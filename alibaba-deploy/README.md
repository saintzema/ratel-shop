# ZEMA 360 — Alibaba Cloud Proof-of-Deployment

Minimal standalone service that calls Qwen Cloud (DashScope), meant to run on
an Alibaba Cloud SAS instance to satisfy the Global AI Hackathon Series
proof-of-deployment requirement. Not the production app — just proof that
something real, calling Qwen Cloud, is running on Alibaba Cloud compute.

## 1. Create the SAS instance

1. Go to the [SAS Console](https://swas.console.aliyun.com/)
2. Click **Create Server**
3. Pick a region close to you
4. Image: **Docker** (application image) — Engine + Compose already installed
5. Pick the cheapest plan
6. Complete payment — instance provisions in ~1 minute with a public IP
7. On the instance card, go to **Reset Password** and set a root password
   (SAS instances have no default password)

## 2. Connect

Easiest: click **Connect** on the instance card in the console — this opens
**Workbench**, a browser-based terminal logged in as root. No local SSH setup
needed. (This is also where you'll take your proof-of-deployment screenshot.)

## 3. Open the firewall port

In the console: your instance → **Firewall** tab → **Add Rule** → custom TCP
port `8080`, source `0.0.0.0/0`.

## 4. Upload and run this folder

From your local machine, copy this folder to the instance (replace the IP):

```bash
scp -r alibaba-deploy root@<your-instance-ip>:/root/zema360-qwen-proof
```

Or paste the three files (`server.mjs`, `Dockerfile`, `docker-compose.yml`)
directly into Workbench using `nano` / `vi` if `scp` isn't convenient.

On the instance, set your Qwen Cloud API key and start it:

```bash
cd /root/zema360-qwen-proof
echo "DASHSCOPE_API_KEY=sk-your-real-key-here" > .env
docker compose up -d
docker compose ps        # confirm it's "running"
```

## 5. Verify it's actually calling Qwen Cloud

```bash
curl http://localhost:8080/health

curl -X POST http://localhost:8080/agent/price-check \
  -H "Content-Type: application/json" \
  -d '{"productName": "iPhone 15 Pro Max"}'
```

You should get back a real price estimate generated by Qwen — that response
proves the deployed instance is genuinely calling Qwen Cloud, not just
running an empty container.

## 6. Take the proof-of-deployment screenshot

In the SAS console → your instance → **Workbench**, with the terminal open
showing `docker compose ps` (status: running) and ideally the `curl`
response from step 5 visible in the same screenshot. That's your visual
evidence for the submission.
